# unresolved-dependencies

Category: [correctness](/reference/rules#correctness). Default: `error`. Fixable: no. Since: 0.1.0.

## What it does

Reports an import that oxcruise cannot resolve to a file or a package.

## Options

* `ignore`: globs for virtual modules and generated code.
  The rule matches each glob against the import specifier and against the path of the importing module.

## Configure the rule

```json
{
  "rules": {
    "unresolved-dependencies": "warn"
  }
}
```

To set options, use an object: the `level`, then the options of the rule.
