# internal-modules

Category: [restriction](/reference/rules#restriction). Default: off. Fixable: no. Since: 0.1.0.

## What it does

Restricts access to `internal` directories, as the Go language does.
Only code under `a/b/` can import a module under `a/b/internal/`.
The rule checks dependencies on local modules.

## Options

* `marker`: the directory name that makes code internal. The default is `internal`.

## Configure the rule

```json
{
  "rules": {
    "internal-modules": "error"
  }
}
```

To set options, use an array: the level first, then an object with the options.
