## Correctness

Default level: `error`.

* [`no-circular`](/reference/rules/no-circular): Reports dependencies that are part of a circular chain of imports.
* [`no-cross-package-relative`](/reference/rules/no-cross-package-relative): Reports relative imports that reach into another workspace package, for example `../other-package/src/x`.
* [`no-dev-deps-in-prod`](/reference/rules/no-dev-deps-in-prod): Reports a production module that imports a package from `devDependencies` only.
* [`no-test-imports`](/reference/rules/no-test-imports): Reports a non-test module that imports a test file or a test directory.
* [`no-undeclared-deps`](/reference/rules/no-undeclared-deps): Reports imports of installed npm packages that no `package.json` section declares.
* [`no-unresolvable`](/reference/rules/no-unresolvable): Reports an import that oxcruise cannot resolve to a file or a package.

## Suspicious

Default level: `warn`.

* [`no-deprecated`](/reference/rules/no-deprecated): Reports imports of deprecated Node.js built-in modules and deprecated npm packages.
* [`no-duplicate-deps`](/reference/rules/no-duplicate-deps): Reports a package that more than one `package.json` section declares, for example both `dependencies` and `devDependencies`.
* [`no-orphans`](/reference/rules/no-orphans): Reports modules that no other module imports and that import no module.

## Restriction

Default level: `off`.

* [`internal-modules`](/reference/rules/internal-modules): Restricts access to `internal` directories, as the Go language does.
* [`layers`](/reference/rules/layers): Enforces a layered architecture: a layer can import only the layers that `allow` lists for it.
* [`no-optional-deps`](/reference/rules/no-optional-deps): Reports use of optional dependencies.
* [`no-peer-deps`](/reference/rules/no-peer-deps): Reports use of peer dependencies.

## Nursery

Default level: `off`.

* [`no-unused-deps`](/reference/rules/no-unused-deps): Reports a package that a `package.json` declares and that none of its modules imports.
* [`no-unused-exports`](/reference/rules/no-unused-exports): Reports exports that no other module imports.
* [`no-unused-files`](/reference/rules/no-unused-files): Reports source modules that no path from an entry point reaches.

## Conventions

A convention tells the `no-unused-*` rules what a tool loads by itself.
A convention is active in a `package.json` that declares one of its packages.
When a convention lists no packages, it is always active.

* The entry points are globs relative to that `package.json`. They are files that the tool loads.
* The `no-unused-deps` rule counts the packages of a convention as used.
* Use the `conventions` option of the rules to switch conventions off or to select some of them.
