# duplicate-packages

Category: [suspicious](/reference/rules#suspicious). Default: `warn`. Fixable: no. Since: 0.1.0.

## What it does

Reports a package that more than one `package.json` section declares,
for example both `dependencies` and `devDependencies`.
The rule ignores type-only imports.

## Configure the rule

```json
{
  "rules": {
    "duplicate-packages": "error"
  }
}
```
